# Quick Validation

1. Frame the customer, problem, geography, and offer.
2. Identify key assumptions.
3. Check obvious competitors and substitutes using available research.
4. Assess pain, demand, differentiation, feasibility, and major risks.
5. Run Devil's Advocate.
6. Score viability and research confidence separately.
7. Decide BUILD / TEST / MODIFY / REJECT.
8. Recommend one cheap experiment with measurable thresholds.
9. State what was not researched.

Do not describe a quick screen as exhaustive due diligence.
