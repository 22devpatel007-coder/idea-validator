# Market Analysis

Define the initial customer segment. Investigate problem frequency, urgency, severity, cost of inaction, buying triggers, budget owner, reachable customer count, and market/regulatory changes.

Prefer bottom-up sizing:
- target customer population;
- reachable subset;
- sourced assumptions;
- plausible adoption only when evidence supports it.

Distinguish TAM, SAM, and realistic SOM. Never invent precise numbers. If inputs are missing, provide a sizing framework.
